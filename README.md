# Rijschool Stripes, concepten-site

Statische kopie van https://rijschoolstripes.nl voor het uitwerken en tonen van concepten (niet live, niet indexeerbaar).

- Alle trackingscripts (GTM, GA4, Ads, PixelYourSite, Meta, TikTok) zijn verwijderd.
- Formulieren (Gravity Forms) versturen niets.
- noindex via meta robots, X-Robots-Tag (vercel.json) en robots.txt.
- Vorige inhoud (7 taalpagina-demo's) staat in de git-historie, laatste commit c0f7473.
